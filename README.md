# WCAG 2.2: Web Content Accessibility Guidelines, with examples

A single-page, scrollable guide to WCAG 2.2. Each success criterion at Levels A, AA and AAA, plus the criteria that are new in 2.2, comes with side-by-side examples that fail and pass. The page ends with a swipe quiz and an introduction to responsive web design.

**Live page:** https://anasmations.github.io/wcag-web-content-accessibility-guidelines/

The page itself follows WCAG: skip link, visible focus, 44 px targets, a pause control for animations, and support for "reduce motion".

Source: [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/). Examples are illustrative; check each criterion's full wording before auditing.
